## 修复 GitHub Actions 自动打包失败（deprecated upload-artifact v2）

- 现象：三个平台（ubuntu/macos/windows）的 build run 全部秒拒，报 `actions/upload-artifact: v2` deprecated。
- 根因：远程仓库的 workflow（commit 7693df1）用了 `dAppServer/wails-build-action@v2`，该三方 action 内部调用已废弃的 `actions/upload-artifact@v2`，被 GitHub 自动判失败。仓库自身的 upload-artifact 其实已是 v4。
- 修复：本地已有重写版 workflow（commit 7d21806，改为直接 `wails build`，不再用 wails-build-action）但一直没推送。追加 commit 057a434（setup-go 1.23 → 1.27 对齐 go.mod 的 go 1.27.0），推送后新 run 32965139860 正常进入编译阶段。
- 教训：诊断 CI 失败时先 `git ls-remote` 对比远程 HEAD 与本地，本地修复可能只是没推上去。

## 仓库环境备忘

- 本仓库有后台自动同步工具，每隔几分钟以 "Sync: <时间戳>" 为 message 自动 commit + push；它会清掉 `.git/refs/remotes/`（origin/main 显示 [gone]），fetch 后 ref 又消失属正常现象，不影响 push。
- 本机无 gh CLI，查 GitHub Actions 状态用公开 API：`api.github.com/repos/wyzzgzhdcxy/wcj-go-text/actions/runs`。
