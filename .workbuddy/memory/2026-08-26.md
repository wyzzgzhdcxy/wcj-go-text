## 2026-08-26 续8 - 修复“菜单显示设置”页布局错乱

- 现象：菜单显示设置页（menuSettings.vue）很多菜单显示不出来 / 布局错乱。
- 根因1（主）：该页 scoped 样式未显式声明 `display`，继承了全局 style.css 里 `.page`/`.card`/`.card-body` 的 flex 规则。`.card-body` 变成横向 flex，12 个分组被挤在一行；`.card` 又被 `flex-shrink`+`min-height:0`+`overflow:hidden` 压缩裁切，底部内容不可见。

- 根因2：页面数据依赖 `window.__wcjMenuData__`，只在 App.vue 侧边栏底部“全部”菜单点击时（handleMenuCmd）才生成，刷新/直达页面时数据缺失 → 分组为空。
  - 修复：App.vue 加 `created()` 钩子提前调用 `buildMenuGroups()`（Vue3 子组件 mounted 先于父组件，必须放 created 才赶得上）。

## 2026-08-26 续11 - 修复 build.bat 报"不是内部命令"（编码/换行/引号三坑）

- 现象：build.bat 执行报一堆 `'d.bat'`、`'proper'`、`'owershell'`、`'UILD_TIME'`、`'n.BuildTime'`、`'build]'` 不是内部或外部命令（命令被拆碎、开头缺字符）。
- 根因（三坑叠加）：
  1. **换行符是 LF**（`xxd` 看 `@echo off` 后是 `0a` 无 `0d`），而正常 build_tag.bat 是 CRLF（`0d 0a`）。cmd 对 LF-only 批处理解析错乱。
  2. **`for /f ... in ('...')` 嵌套单引号**：`in ('powershell ... "Get-Date -Format 'yyyy-MM-ddTHH:mm:ss'"')` 里，for 用单引号定界命令，内部单引号让 cmd 提前截断。
  3. **UTF-8 无 BOM + 中文 + `chcp 65001` 靠后**：cmd 默认按 GBK 读文件，中文注释在 chcp 生效前已被错误解码。
- 修复：build.bat 改为 **GBK 编码 + CRLF 换行**（中文 Windows 原生代码页，cmd 直接读对，删掉 chcp 65001），for 命令改用 **usebackq 反引号**定界：`for /f "usebackq delims=" %%I in (`...`) do ...`，消除嵌套单引号。
- 方法：Write 写 UTF-8 内容 → Python `open(p,'w',encoding='gbk',newline='')` 读 UTF-8 写 GBK + 手动 `\r\n`。验证：`file` 看 CRLF、`iconv -f GBK -t UTF-8` 看中文正常。
- 注意：build.ps1 仍是 UTF-8 无 BOM（含中文注释但可执行代码纯 ASCII，暂能跑）；若将来在 ps1 可执行代码里加中文，需转 UTF-8 with BOM（PowerShell 5.1 靠 BOM 识别 UTF-8）。
