## CI 构建失败修复（vite 8 esbuild 遗留，2026-08-27）
- 症状：CI wails build 前端编译报 `Failed to load transformWithEsbuild ... requires esbuild to be installed separately` + `Cannot find package 'esbuild'`。
- 根因：vite 8 把 esbuild 从内置依赖移除（改用 rolldown+oxc），但 vite.config.js 仍残留 `build.minify: 'esbuild'`，触发已废弃的 transformWithEsbuild 路径。
- 修复：`minify: 'esbuild'` → `minify: 'oxc'`（vite 8 默认压缩器，无需额外依赖）。本地验证 `vite build` 通过（975ms）。
- 教训：升 vite 8 时除 minify 外，optimizeDeps 配置语义也已变化，升级时需同步检查 vite.config.js 所有 esbuild 相关项。
